# Codex Plus 0.163.0-plus.0.4.4

Qualified on native x86_64 and aarch64. Publication, main merge and fleet rollout remain separate approvals.

This release adds the Claude advisor workflow and native advisor display. It
also fixes executor startup reconciliation so it does not probe the startup
lock while its executor is alive. Advisor output now tolerates closed stderr
with best-effort diagnostics; failed stdout writes produce a checked failure
after cleanup instead of panicking. Two real closed-descriptor tests cover
these paths, alongside three real stock-daemon startup overlap/control cases.

The advisor defaults to Claude Opus 5.5 (`claude-opus-5-5`) at `xhigh`. On xjp_l20_2 it runs locally; other boxes use the existing `xjp-l20-2` SSH alias. Claude installation and authentication are required only on the central host. The brief and explicitly attached `--context-file` contents travel with the request. The workflow is embedded in `codex-plus advisor --help`; `--provider astra` remains an explicit compatibility option.
