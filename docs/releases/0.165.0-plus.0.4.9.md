# Codex Plus 0.165.0-plus.0.4.9

This candidate moves the Plus frontend to official Codex 0.165.0. The Plus helper
version remains 0.4.9 because its runtime source is unchanged. The complete release
identity includes both versions; this is distinct from 0.163.0-plus.0.4.9.

Plus retains compact command display, Morandi, worker/background status,
Goal/Ultracode and its client-side daemon-update guards. The official stock backend
is not patched. Upstream's default-on reasoning-effort updates are preserved:
supported OpenAI models use configuration updates when effort changes. Private
wire tests verified stable prompt-cache keys; this is not a measured cache-hit or
cost-saving claim. The new default requires the 0.165 stock daemon.

## Qualification before publication

Development builds and focused Rust/private terminal/runtime tests passed on x86
and ARM; see [the assessment](../upstream-0.165.0-assessment.md). Shipping acceptance
still requires fresh complete native packages, their manifests and dependencies,
the existing compatibility/recovery/capture gates, released AP replay and the
paired stock-daemon transition. The source note is frozen with the packages;
the publication companion records actual final results and limitations.

The proposed rollback pair is official Codex 0.163.0 with
`0.163.0-plus.0.4.9`. A retained Plus directory alone does not qualify rollback:
the old stock daemon must read and resume the tested state written by 0.165,
with Plus records preserved. No snapshot fallback is assumed. Unresolved required
checks block shipping acceptance.

## Fleet handoff

Use coordinator protocol 5 and execution record format 1. No new global settings
or instruction block are requested (`agents_md: null`). The handoff requires a
quiet checkpoint, drained executions, a stock-daemon restart and a session restart.
Fleet-config owns the rollout and its user approval.

On each quiet host under the maintenance hold, run the operator's stock npm
installation, Plus installation and `codex-stock app-server daemon update
--from-cli --yes` back to back. Start no new Codex work between those steps.
Record and preserve the old stock CLI/daemon identities and restoration inputs
alongside the retained Plus package; automatic old-stock retention is not assumed.
Rollback restores stock 0.163.0 through npm and the daemon updater together with
Plus 0.163.0-plus.0.4.9, at another authorized quiet checkpoint.

The observed fleet still includes idle 0.4.8 and 0.4.9 TUIs. Their transition
coverage must be stated explicitly in final qualification. After the stock/Plus
pair is switched, exit and resume old TUIs to load the new frontend before resuming
ordinary work. Preserve any package still in use by another workstream.

Publication, main merge, installation and actual session restart are recorded
separately. This candidate note does not claim that any of them occurred.
