# 0.163.0-plus.0.4.9

This revision improves release preparation and documentation. The frontend patch
and runtime source remain unchanged from 0.4.8; the helper package version advances
to 0.4.9. It keeps the official 0.163.0 daemon, coordinator protocol 5 and execution
record format 1.

## Release preparation

- Native and AP prerequisite checks validate host pins, fixture inputs, production
  libcap discovery, the canonical previous package and replay dependencies before
  allocating an attempt. Their output distinguishes readiness from qualification.
- The release book defines normal-main synchronization before new releases,
  independent frozen product/tooling revisions, local package approval and the
  lifetime of untouched release worktrees.
- Publication guidance provides the existing draft/public identity and asset
  verification commands. Recovery and reuse limits are explicit.
- Pilot lessons clarify attempt-local audit outputs, compatibility's runtime
  baseline/completion audit, and preparing review commands before expensive launches.

This is the first pilot of the shared release skill against the project-owned
[release book](../release-book.md). The skill supplies the entry point; the book
and checked-in tools retain the project-specific commands and acceptance gates.
[Pilot notes](0.163.0-plus.0.4.9/pilot-notes.md) record corrections and timing limits.
